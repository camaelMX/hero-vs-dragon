# 怪卡系统与成长

---

## 一、怪卡系统

### 大循环结构（第一幕）

- 第一幕 = **3 大轮旅程**（林地 / 雪线 / 龙巢之路），每大轮 **8 步**，走完进入该轮节点（龙巢为最终 Boss）
- 每步从牌堆**抽 3 张怪卡三选一**，未选的弃掉
- 卡池有限：每大轮固定 8 次抽卡，**没有刷的余地**——这是"选难度"张力成立的前提
- 打赢的怪卡**踩扁铺在脚下成为道路**（结局演出复用此资产：复仇线是尸骸铺路，真结局是救赎之路，幻觉线化作墓碑）

### 挑战等级旋钮

每大轮出发前设定，决定本轮抽卡池的基准档位与奖励系数：

| 档名（提案，待定稿） | 基准档位 | 奖励系数 |
|---|---|---|
| 祈祷 | 低 | ×0.8 |
| 猎杀 | 中 | ×1.0 |
| 血誓 | 高 | ×1.3 |

### 动态地板（防"Boss 门前是哥布林"）

- 第 1~3 步：按旋钮档位抽卡
- 第 4~6 步：最低威胁 **+1 档**
- 第 7~8 步：最低威胁 **+2 档**
- 奖励随实际档位凸增长（见参数表）

### 卡面信息透明

卡面明示：威胁值（★）、怪物名与形象、预计经验、掉落预告。**信息透明才叫决策，不透明叫赌博。**

## 二、第一幕成长

- **升级**：经验达标，按模板自动加属性（不做加点，节奏快）
- **宝物**：怪卡掉落，进入装备栏（暴击流/反伤流/闪避流遗物雏形）
- 商店出售：血瓶、定神香、平价宝物

## 三、第二幕成长：血脉技能树

掉落系统退场，取而代之的是**魔力点数**灌入三系血脉树：

| 分系 | 风格 | 对应 QTE 玩法 |
|---|---|---|
| 魔焰 | 高攻/暴击 | 进攻压制 |
| 梦魇 | 闪避/控制 | 闪避 QTE 高风险流 |
| 血脉 | 坦度/反伤 | 完美防御 QTE 流 |

- 魔力点数来源：**屠杀/追杀**掉落；放走线无魔力点（真结局只靠等级成长 → 更难，由"慈悲援军"补偿）
- 三系各 1 条直线上若干节点，不做复杂树——决策在"主哪系"，不在"排布"

## 四、魔化技能组（隐藏第六系）

**触发：第二幕 SAN = 0。不结算，不 Game Over。**

- 魔化觉醒演出（锁链崩断、视界褪色、人类眼中的"你"变成龙）
- 解锁**魔化技能组**：灭世魔焰（全屏即杀级 AoE）、每回合自愈、伤害倍率爆炸——**纯数值碾压，不做平衡。它就是叙事奖励**
- **血洗终章**：剩余流程自动收束为单方面碾压的加冕行军——士兵成建制逃跑、跪地、城门自开；爽感给足但不拖：无敌状态只存在 20~30 分钟
- 最终战保留勇者（不退、不跪——与第一幕"魔物不撤退"镜像），数值悬殊的碾压局
- 打完 → 隐藏结局《勇者斗恶龙》（见《03》）

## 五、数值设计方法论

1. **反推法**：先定 Boss → 反推玩家达标战力 → 反推卡池经验/掉落表
   - 第一幕终 Boss 父王：固定数值。目标：玩家以"血誓档 + 均衡选择"到达时胜率约 70%
   - 第二幕终 Boss 勇者：**固定数值**（核心承诺：Boss 永远一定），第一幕他的招式表就是攻略
2. **第二幕小怪与主角等级同倍率缩放**（纯数值对纯数值，曲线好调）
3. **模拟校准**：脚本自动模拟 1000 局三种策略——"无脑苟"（全选低威胁）、"均衡"、"贪心"（全选最高能打赢的）
   - 验收标准：贪心胜率最高但战败率显著；无脑苟打 Boss 胜率 < 30%；均衡曲线平滑
   - 模拟不过 → 调凸函数系数/动态地板，不改机制
4. 可调旋钮清单：完美防御反弹系数（1.2~2.0）、普通减伤率、动态地板档数、杀孽→Boss 增益、放走双倍经验（备用）
