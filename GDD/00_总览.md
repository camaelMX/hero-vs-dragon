# 《勇者斗恶龙：魔子》GDD 总览

版本 v0.2 · 2026-11-07 · 状态：设计迭代中（预计还要改数版）

---

## 一句话定位

玩家扮演勇者小队里的"第四人"——一个能听懂魔物语言的见习圣骑士。
他不知道自己是魔王之子，是人类养大的武器。
回合制 + QTE 的叙事向卡牌选择 RPG。

## 核心体验三关键词

1. **自己选难度**：走向 Boss 的每一步都由玩家从三张怪卡里挑一张——挑弱的养不起自己，挑强的可能翻车，卡池有限，没有刷的余地
2. **人性当资源**：SAN 只被"你做了什么"改变（杀戮、战败、安抚），永不被"你打得漂不漂亮"改变。第一幕省着用，第二幕只出不进
3. **标题即剧透**：《勇者斗恶龙》是人类视角的书名号。第一幕你是讨伐者，最后你会发现——被讨伐的是父王，讨伐队里藏着的是你

## 核心循环

```
大循环（每大轮）：
  村庄设挑战等级 → 每步三选一怪卡 → 回合制战斗 → 胜利踩卡铺路
  → 8 步走完 → Boss 房

小循环（每场战斗）：
  速度序轮流出手 → 敌方攻击触发 QTE（防御/闪避）
  → 我方回合（攻击·暴击几率 / 道具）

幕结构：
  第一幕（四人小队·打魔物）→ 真相时刻（SAN 闸门）
  → 第二幕（独行·打人类·SAN 只降不升）→ 四结局之一
```

## 特色系统速查

| 系统 | 一句话 |
|---|---|
| QTE 战斗 | 完美防御 = 免伤 + 防御力 ×1.2~2 反弹（参数可调）；闪避 = 成功免伤 / 失败吃满 + 失去行动 |
| SAN | 心智/封印计量表；牧师"安抚"回 SAN 但永久扣最大生命 |
| 怪卡三选一 | 挑战等级旋钮 + 步数动态地板，Boss 门前绝不出现哥布林 |
| 踩卡铺路 | 打赢的怪卡铺在脚下成为道路——结局演出复用此资产 |
| 屠杀/放走 | 第二幕每场胜利后的抉择：装备与杀孽，或报恩与慈悲 |
| 血脉技能树 | 第二幕成长取代掉落：魔焰（暴击）/ 梦魇（闪避）/ 血脉（反伤） |
| 魔化 | SAN=0 不结算：解锁碾压级技能组，血洗终章，隐藏结局 |
