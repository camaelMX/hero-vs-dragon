# Godot 新手指南（你要做什么）

> 你是 Godot 小白，没问题——分工是：**我写全部代码和场景，你负责三件事：装编辑器、按 F5、说"哪里手感不对"**。
> 这份指南把你要做的事写到"照着点"级别。

---

## 一、Godot 是什么，30 秒版

- 免费开源的游戏引擎，**没有版税、没有分成、没有账号**，一个 zip 就能跑
- 代码用 GDScript（语法像 Python），2D 支持极好，独立游戏圈主力引擎（SaGa 前制作人、Brotato、Cassette Beasts 都用它）
- 我们用的是 **Godot 4.x**（注意不是 3.x，两者互不兼容）

## 二、安装（唯一需要动手的环节）

**方式 A：让我在本机帮你装（推荐）**。这台机器就是开发机，我可以用命令行把官方编辑器装好、建好工程，你到时候直接双击图标打开。你说一声"装吧"即可。

**方式 B：自己装**，步骤：
1. 打开 [godotengine.org/download](https://godotengine.org/download)
2. 选 **Godot 4.x - Standard** 版（**不要**选 ".NET" 版，我们不用 C#）
3. Linux 下载 zip，解压到任意目录（如 `~/godot/`），里面就一个可执行文件 `Godot_v4.x.x`
4. 双击运行——Godot 是**免安装**的，双击就是编辑器，再双击还是它

> 也可以走 Steam 搜 "Godot Engine" 安装，效果一样，自动更新更省心。

## 三、打开我们的项目（装好后只做一次）

1. 双击 Godot → 左侧点 **Import（导入）**
2. 选择 `/home/camael/AI/game/project.godot`（我建好工程后这个文件就在）
3. 点 **Import & Edit**
4. 进入编辑器后按 **F5**（或左上角 ▶ 按钮）→ 运行游戏

以后每次打开：直接双击 Godot → 中间列表会出现项目 → 点开 → F5。

## 四、编辑器五分钟速览（认四个区域就够）

```
┌─────────────┬──────────────────────┬──────────────┐
│ 左：场景树    │   中：视口(游戏画面)    │ 右上：检查器    │
│ Scene       │                      │ Inspector    │
│ (当前的部件)  │                      │ (选中件的性格)  │
│             │                      ├──────────────┤
│             │                      │ 右下：文件系统  │
│             │                      │ FileSystem   │
│             │                      │ (res:// 的文件)│
├─────────────┴──────────────────────┴──────────────┤
│ 下：输出 Output（报错和打印都在这里）                   │
└───────────────────────────────────────────────────┘
```

三个核心概念（知道词就行，代码我来写）：
- **节点 Node**：积木块。一张图、一个音效、一个血条都是节点
- **场景 Scene**：拼好的积木组合，可复用。比如"一张怪卡"是场景，战斗界面也是场景
- **信号 Signal**：积木之间的"喊话"。比如"按钮被按了"喊一声，别的节点听到了做出反应

## 五、你的日常流程（试玩循环）

```
双击 Godot → 打开项目 → F5 玩 → 觉得不对/不舒服 → 截图或描述 → 我改
```

试玩时重点帮我盯这些（都是手感问题，只有玩的人能发现）：
- QTE 按下时机的"手感"：窗口太快？太快按不到？提前量怪？
- 完美防御成功那一下"爽不爽"
- 战斗节奏：一场太久还是太短
- 卡牌三选一时信息够不够看清

## 六、常见坑（提前排雷）

## 七、词汇表（看代码注释时会遇到）

| 词 | 意思 |
|---|---|
| `res://` | 项目根目录（就是 `/home/camael/AI/game/`） |
| Node / Scene | 积木 / 积木组合 |
| Signal | 节点间事件广播 |
| Tween | "让这个东西在 0.3 秒内滑到那儿"的动画工具 |
| Export 变量 | 在编辑器检查器里能直接改的参数（数值表里的可调旋钮都会做成这种） |
| GDScript | Godot 的脚本语言，像 Python |
| FPS | 帧率。逻辑帧固定 60，物理不受掉帧影响 |
