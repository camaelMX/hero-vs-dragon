# 战斗系统

---

## 一、回合骨架

- **经典回合制，速度值排序**（不做 ATB 条）：每场战斗开始时按速度值从高到低排定行动序列，逐个执行
- 4 人队伍 = 勇者 / 牧师 / 法师 / 主角（玩家）三个 AI + 一个玩家角色
- **QTE 独属于玩家（主角）**，其余角色行动由 AI 判断、自动结算，不设 QTE——保住 QTE 的"勇者神经"专属手感
- 回合流程：
  ```
  行动序列轮转
  ├─ 我方角色回合
  │   ├─ 主角：玩家操作（攻击 / 道具）
  │   └─ AI 队友：自动判断（见第四节）
  └─ 敌方回合
      └─ 敌人施放攻击 → 触发主角侧反应 QTE（防御 / 闪避，二选一预先设为"待机反应"）
  ```

## 二、主角动作集

### 第一幕（见习圣骑士）

| 动作 | 类型 | 说明 |
|---|---|---|
| 攻击 | 主动 | 基础伤害，带暴击几率（纯数值，无 QTE） |
| 道具 | 主动 | 血瓶 / 定神香 / 情报道具 |
| 防御姿态 | 反应预设 | 本回合内敌攻触发**防御 QTE** |
| 闪避姿态 | 反应预设 | 本回合内敌攻触发**闪避 QTE**（高风险高回报） |

### QTE 规格

| QTE | 判定 | 成功 | 失败 |
|---|---|---|---|
| 防御 | 敌人攻击命中瞬间按键（时机判定，纸马式） | **完美防御**：完全免伤 + 反弹（防御力 ×1.2~×2，系数进参数表可调） | 普通防御：减伤（默认 50%，参数可调） |
| 闪避 | 窗口更小的时机判定 | **完全免伤** | **吃满伤害 + 失去下回合行动** |

- 暴击：纯几率属性（基础 5%，装备/血脉树提升），无操作成分
- **铁律：一切战斗表现不影响 SAN**（SAN 影响命中率，反向不存在）

### 第二幕（独行魔子）

- 无队友，主角动作集扩展为血脉技能树技能（见《06_怪卡与成长》）
- QTE 机制不变，敌人招式更密集（多段攻击、连击 QTE 链）

## 三、敌人行为

### 第一幕（魔物）

- **所有魔物不撤退**——战至死亡（伏笔：它们是来夺回王子的亲卫与游猎队）
- 部分高阶魔物（亲卫系）对主角的攻击"留手"：主角受到的致命伤害有概率被"迟疑"降低（演出：爪子在最后一寸拐开）——数值上做成轻微减伤 Buff，主题上是伏笔
- 群怪卡：哥布林×3、雪狼群等，法师 AoE 的用武之地

### 第二幕（人类）

- **士兵血量 <30% 时尝试逃跑**：玩家可**追杀**（杀孽+1，SAN-10）或**目送**（放走线，可能触发报恩）
- 逃跑演出：拖刀、瘸行、回头的那一眼——放走从"战后弹窗"变成战场上的实时抉择
- 军官/圣骑士单位会"督战"：附近有军官时士兵不逃跑——先杀军官才能放人走，构成小型战术目标
- 敌方目标选择（1000 局模拟校准 v0.3）：**12% 狙牧师**（猎杀治疗者，否则"贪心"零风险）、35% 偏向主角、其余随机

## 四、AI 队友行为逻辑

| 角色 | 优先级逻辑 | 备注 |
|---|---|---|
| 勇者 | 血量最低敌人 > 高威胁敌人；血量 <40% 时自保 | 输出手。他的招式表 = 第二幕最终 Boss 战的镜像（玩家全程被"教练"） |
| 牧师 | ① 队友血量 <35% 治疗 ② **安抚（玩家手动授权开关开启时）** ③ 普攻 | 安抚 = SAN+15 / 永久 -5 最大生命 / 鳞纹+1；**授权开关默认关闭**，玩家舍不得也要自己按 |
| 法师 | 敌人数量 ≥2 用 AoE，单体用高伤法术 | 法力管理做简化（冷却制） |

## 五、战败与撤退

| 情形 | 第一幕 | 第二幕 |
|---|---|---|
| 战败 | 全队战斗不能：卡不消耗，原地重试，保留伤势（HP 不回复）+ 损失金币 30；**倒地队员以 30% 最大生命重整**（0 血重试=开局即死，实测修正）；**SAN -20** | 主角重伤逃脱到上个安全点：同样按 30% 重整 + **SAN -20**（无人救援，更重） |
| 主动撤退 | 撤离该步（卡弃掉），**SAN -10**（"怂了"也是代价） | 同左，并使敌人情报永久可见 |
| SAN=0（第一幕） | 心防崩溃：提前结算 → 幻觉结局 | **不结算**：触发魔化线（见《06》） |

## 六、演出规则

- **"叽里咕噜说什么呢"固定节拍**：主角每次触发"听懂"演出，随后必接队友吐槽（台词见剧情稿）——伏笔自动化
- 低 SAN 演出：SAN<50 命中 -10%，画面噪点+心跳音；SAN<25 追加 -20%，敌人轮廓偶发"翻转"
- 完美防御成功：反弹伤害 + 短暂时停 + 金属音效（手感核心，优先打磨）
