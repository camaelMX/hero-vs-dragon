# SAN 与选择经济

---

## 一、SAN 定位

SAN = 主角的**心智 / 封印**计量表。上限 100。

它衡量的是"你是谁"：100 = 教团要的完美容器（或觉醒后完整的人性），0 = 不再是人。

**铁律：一切战斗表现（QTE 成败、挨打、暴击）不影响 SAN。**SAN 只被"你做了什么"改变。

## 二、SAN 全规则

### 第一幕

| 变动 | 数值 | 说明 |
|---|---|---|
| 战败 | -10 | 倒地队员以 30% 最大生命重整（幸存者伤势保留），可重试。**v0.3 由 1000 局模拟校准：-20 会让"苟"策略八成心防崩溃** |
| 主动撤退 | -10 | 弃卡 |
| 定神香 | +25 | 商店购买（金币出口） |
| 牧师安抚 | +15 | **永久 -5 最大生命**；鳞纹+1；玩家手动授权开关 |
| 升级 | 不回 SAN | （已否决升级回 SAN 方案） |

阈值效果：
- **SAN < 50**：命中率 -10%；画面噪点、心跳音
- **SAN < 25**：命中率再 -20%；敌人轮廓偶发"翻转"
- **SAN = 0**：心防崩溃 → 提前结算 → 幻觉结局

**真相时刻闸门**（第一幕 Boss 战·牧师之死后判定）：
- SAN ≥ 50 → 封印碎，觉醒，进入第二幕
- SAN < 50 → 封印撑住 → 幻觉结局

### 第二幕

| 变动 | 数值 | 说明 |
|---|---|---|
| 初始 | 100 | 觉醒即满值——新生 |
| 审判（每场，处决降兵/俘虏） | -15 | 按钮文案「审判」——主角接过教团定他罪的那个词 |
| 追杀溃兵（每次） | -10 | 逃跑敌人被追杀 |
| 杀商人 | -25 | 一次性事件 |
| 战败 | -10 | 重伤逃脱（30% 重整） |
| **恢复手段** | **无** | 人性不可逆 |

- **SAN = 0 → 不结算，直接化身魔龙**（用户 2026-11-07 定稿）：变身演出（锁链崩断、鳞甲吞没全身）→ **新立绘 + 全新魔龙技能组**（数值碾压、不做平衡——"秒天秒地"的力量幻想本身就是叙事奖励）→ 血洗终章以魔龙形态进行 → 隐藏结局
- **终局 SAN = 100（即全程零杀）→ 真结局**
- **终局有杀孽且 SAN > 0 → 复仇结局**

## 三、第二幕选择经济

### 每场胜利后的抉择

| 选择 | 获得 | 代价 | 叙事 |
|---|---|---|---|
| 审判 | 敌人掉落（装备/补给）+ 杀孽 +1 | SAN -15 | 战利品的味道。释放是善良，审判是力量——诱惑结构就在这 |
| 追杀溃兵 | 掉落 | 杀孽 +1，SAN -10 | 审判线的战场内变体：士兵 <30% 逃跑时追上去 |
| 释放 | **全额经验** + 报恩（随机：血瓶/干粮/情报），**SAN 不变** | 溃兵带回消息，后续遭遇变强 | "教团说的怪物会撒谎里，没提到的事" |

设计原则：
- **经验来自"击败"，与杀不杀无关**——真结局只是"穷"，不是"废"
- 装备走审判线，**消耗品与情报走释放线**：两条线拿的东西不同，而非多少不同
- 慈悲的回报：释放的士兵在真结局线最终战前出现**挡刀/助阵**（援军演出）

### 商人事件（一次性，第二幕中段）

| 选择 | 获得 | 代价 |
|---|---|---|
| 杀商人 | **全部库存**（教团特供装备，实力指数型增长，库存固定清单、只此一次） | 杀孽+1，SAN-25，商店永久消失 |
| 驱赶 | 一次免费整备 | 商店永久消失（他跑了） |

- 杀商人 = 爽游路线的爆发点，指数增长**封顶于固定库存**，不无限刷
- 备用调参旋钮：杀孽值 → 最终 Boss 增益系数（试玩后觉得复仇线太轻松再启用）

### 金币的死亡

- 金币只在第一幕有意义：商店（血瓶/定神香/宝物）= 第一幕的风险预算
- 第二幕士兵掉落改为补给与道具，不再走金币——**金币无用本身就是叙事**：你杀光了世上所有愿意跟你交易的人

## 四、第一幕经济

| 资源 | 获取 | 出口 |
|---|---|---|
| 经验 | 战斗（全额） | 升级（模板属性） |
| 金币 | 战斗、宝物变卖 | 商店：血瓶 / 定神香 / 宝物 |
| 宝物 | 怪卡掉落 | 装备栏（勇者向属性） |
| SAN | 定神香 / 安抚 | 见第二节 |
